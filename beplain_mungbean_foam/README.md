# beplain 녹두 약산성 클렌징 폼 — 상세이미지

쇼핑몰 상품설명란에 올리는 **세로형 상세이미지(폭 860px)** 입니다.
HTML/CSS로 디자인하고 브라우저로 JPG·GIF를 뽑아서, 문구를 바꾸면 바로 다시 만들 수 있습니다.

## 결과물

```text
export/
├─ beplain_mungbean_foam_860.jpg   # 통이미지 1장 (860 × 25,455px, GIF 자리는 완성된 정지 화면)
├─ preview.html                    # 분할 이미지를 순서대로 이어 붙인 미리보기 (GIF 재생됨)
└─ sections/                       # 쇼핑몰에 올리는 분할 이미지 29장 (JPG 21 + GIF 8)
```

- 쇼핑몰에는 `sections/`의 파일을 **파일명 순서대로** 올립니다. `02-1 → 02-2 → 02-3`처럼 한 섹션이 여러 장으로 나뉜 곳이 있습니다.

## 컨셉

- **원본과 다른 톤:** 비플레인 원본의 형광 라임·검정 대비 대신 아이보리·세이지 바탕에 딥 포레스트 그린을 쓰고, 소프트 라임은 강조에만 씁니다.
- **문구:** 위에 가벼운 명조(고운바탕) 한 줄, 아래에 굵은 G마켓 산스 제목. 핵심 단어에는 라임 형광펜을 칩니다.
- **사진:** 공식 상세이미지에서 글자가 없는 부분만 잘라 크게 씁니다 (모델, 튜브 연출컷, 녹두 트레이, 제형, 임상 사진, 사용법).

## 정보 출처 (2026-10-13 확인)

- 문구·수치·각주: 비플레인 공식몰 상품(branduid=15) 상세이미지에 있는 내용만 사용했습니다.
- 상품 정보 제공 고시: 같은 상품 페이지의 고시 표.
- 그래프·GIF는 위 수치를 그대로 옮겨 직접 그렸고, 거품 영상은 공식 GIF를 다시 편집했습니다.
- 수상 로고 이미지는 쓰지 않고 수상 내역을 문구로만 정리했습니다.

## 수정 · 다시 뽑기

1. 문구는 `index.html`, 디자인은 `assets/css/detail.css`에서 고칩니다.
   - `<section data-slice="이름">` 하나가 분할 이미지 단위입니다.
   - `data-gif="4000"`이 붙은 영역은 4초 한 바퀴를 캡처해 GIF로 저장합니다.
   - `data-gif-img`가 붙은 영역은 안의 움직이는 이미지(`foam.webp`) 프레임으로 GIF를 만듭니다.
2. 브라우저로 `index.html`을 열면 결과를 바로 볼 수 있습니다 (애니메이션도 재생됩니다).
3. JPG·GIF를 다시 뽑으려면 Node.js와 Chrome 또는 Edge가 필요합니다.

```bash
npm i puppeteer-core sharp gifenc
node tools/export.js
```

비플레인을 주제로 제작한 비공식 포트폴리오 작업입니다.
